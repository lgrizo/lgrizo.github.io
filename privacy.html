PNG VAULT MANAGER

Privacy policy

Effective October 14, 2026.

Access and use

This private utility accesses Google Drive files created by the app or explicitly selected by its authorized operator. It uses file contents, names, identifiers, links, sizes, and checksums to organize and verify files. The connected account's email address is used to confirm the intended account; storage quota is read to check the connection.

Storage and sharing

Files remain in the operator's Google Drive, with working copies on the operator's computer. A private database provided by Supabase stores file metadata and folder links. Authorization tokens are stored privately on the operator's device. Data transfers to Google and Supabase use HTTPS.

Files explicitly shared by the operator may be readable by anyone with their link. Other files remain private. Google user data is not sold, used for advertising, or used to train AI models.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and control

Files and metadata are retained while needed by the operator. Access can be revoked in Google Account connections. Revocation stops future access but does not delete existing files, records, or shared links. The operator can remove files and sharing permissions in Drive and request deletion of stored metadata and credentials.

For support or privacy requests, contact the operator using the support address shown on Google's authorization screen. This notice will be updated when data practices change.
